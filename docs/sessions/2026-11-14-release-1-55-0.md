## Discoveries

- **`v1.54.0` was never tagged, and the last two versions have no GitHub
  Release.** `VERSION` has read 1.54.0 since 2026-10-10 (merge commit
  `2a7ec3c`, pull request 89), but the newest tag on the remote is `v1.53.0`
  and the newest published Release is `v1.52.0`. Adopter version gates
  compare against the latest tag, so the fleet has been gated on 1.53.0.
  `git show 2a7ec3c:VERSION` prints `1.54.0`, so that commit is the one to
  tag if the gap is backfilled.
- Dependabot pull requests 106–108 merged earlier the same day and cleared
  the 7 advisories GitHub had been reporting on the default branch; there
  are no open alerts and `npm audit` in `mcp-server/` reports 0.
  `docs/OTS_SOFTWARE.md` OTS-001 still named `^1.31.0`; it now names
  `^1.32.2`.
- `mcp-server/package-lock.json` contains `1.54.0` three times; only the two
  root `version` fields are the framework's. The third is `mime-db`'s own
  version and must not be rewritten by a version-bump search-and-replace.
- A pull request merged while a follow-up commit is in flight silently
  drops that commit: `git push` succeeds, the branch moves, and the merged
  pull request stays at the old head. Check the pull request's state before
  pushing to its branch.

`Unreleased` above it; OTS-001 re-reviewed. Full suite and release checks

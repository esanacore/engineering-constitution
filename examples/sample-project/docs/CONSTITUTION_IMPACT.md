# Constitution Impact: sample-project

> Illustration only. This sample project is a skeleton, so everything below
> is synthetic, including the snapshot numbers: it shows the shape and level
> of evidence of a real report, not a record of work that happened. In a real
> repository the snapshot block is written by
> `bash constitution/scripts/build_impact_report.sh .` and never typed.

## Summary

Sample Project is a small internal web service. It adopted Eric's Engineering
Constitution on 2026-01-12, before any feature work. The two changes that
mattered most so far: a committed credential file was stopped before it
reached the default branch, and every dependency now has an owner and a
review date.

## What It Cost

- Session-start reading is about 30k estimated tokens per agent session
  (`measure_instruction_weight.sh`, 2026-06-30). Accepted; revisit if it
  passes 40k.
- `check_doc_freshness.sh` warned on three refactor-only pull requests that
  needed no documentation change (pull requests 14, 22, 27). Left in warn
  mode rather than `--strict`.
- Adoption took one working day, most of it writing real content into the
  installed templates (`docs/sessions/2026-01-12-adopt-constitution.md`).
